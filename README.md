# SabilKas - Frontend

Single Page Application (SPA) untuk antarmuka manajemen keuangan **SabilKas**.

## Stack
- Vanilla JavaScript (ES6+ Modules & SPA Router)
- Tailwind CSS (CDN)
- Chart.js (Visualisasi Keuangan)
- FontAwesome 6 (Icons)

## Struktur Folder
- `css/` : Stylesheet modular (base, fab, sheets, zakat, shodaqoh, print)
- `js/` : Logic JavaScript modular (api, router, finance, zakat, shodaqoh, ai-chat)
- `index.html` : Entrypoint aplikasi
